Sorteador:
Um aplicativo simples e intuitivo para realizar sorteios de números de forma rápida.

Como funciona o projeto:
O usuário define um intervalo de números (mínimo e máximo) e clica no botão para sortear. O sistema escolhe um número aleatório dentro do intervalo estipulado e exibe o resultado na tela.

Tecnologias Utilizadas:
* HTML5
* CSS
* JavaScript
